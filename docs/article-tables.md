# 文章表格与表格智能体

更新：2026-11-18。已在本地实现并通过验收，尚未提交或部署。

## 核心交互

文章中已有的 HTML / Markdown 表格按规模自动分级增强，无需复制或跳转外部工作区：

- **分级接管**：行数 ≥ 4、列数 ≥ 5 或内容较长的规则表格升级为交互表格；小型参数对照表与含合并单元格的复杂表格仅包裹横向滚动容器，保持原生紧凑阅读体验。
- **按需加载与 OSS 兼容**：仅当正文存在待升级表格时才动态加载本地固定版本 Tabulator 6.3.1，并兼容 `global.siteInfo.oss` 静态资源前缀。
- **打卡进度与视图保存**：第一列提供完成打卡复选框与行号按钮，顶部实时展示完成进度条，支持“只看未完成”快捷筛选；打卡状态、隐藏列、列宽与分组列按“文章 ID + 版本 ID + 表格序号”保存在本地存储中。
- **单击查看完整内容**：长文本以两行紧凑展示，单击单元格非链接区域或点击行号即可展开详情与智能体面板，兼容桌面端与手机触屏。
- **原页展开**：点击「展开」后表格在当前文章中占满可用宽度，桌面端并排显示详情，手机端上下排列。点击「收起」或按 Esc 恢复阅读布局。短列按内容收紧，长列分享可用宽度，手动调整的列宽优先。
- **兼容多版本切换与划线评论**：暴露 `window.initArticleTables` 与 `window.resetArticleTables` 支持版本切换自动重挂载；保留隐藏源 `<table>` 并隔离 `.pai-article-ui`，不改变 `selection.js` 划线定位指纹。

## 表格智能体与学习助教

入口为「表格智能体」，兼顾流式单行助教与工具调用智能体：

- **快捷学习助教（SSE 流式 + 独立缓存）**：「讲解知识点」「学习顺序」「出自测题」走 `/api/tables/learning-help/stream` 实时流式输出，按 `行号 + 操作类型` 独立缓存结果，切换按钮不覆盖旧回答、不重复扣费；自测题参考答案默认折叠，代码块采用纯 DOM 安全渲染。
- **表格工具智能体（`/api/tables/agent`）**：在输入框右下角点击「发送」或按 Ctrl / Cmd + Enter 提交指令，支持 DeepSeek Tool Calls，内置三个请求级本地工具：

| 工具 | 执行结果 |
| --- | --- |
| `read_table` | 分页搜索或读取表格行，返回行号、截断标记与单元格内容 |
| `set_table_view` | 筛选、排序、调整显示列，返回确定的行号和列号并同步应用到页面表格（支持一键恢复全部视图） |
| `export_table` | 生成当前筛选与列配置的 CSV，在回答卡片内提供一键下载按钮 |

## 安全与配额边界

- `TableException` 继承 `ForumException`，配合 `ForumExceptionHandler` 原样返回 400 / 401 / 403 / 429 / 502 / 503 状态码与提示文案；未登录点击助教自动拉起 `#loginModal`。
- 写接口校验 `X-Pai-Table: 1` 请求头并优先读取 `X-Forwarded-Host` / `X-Forwarded-Proto` 比对 `Origin`，兼容反向代理。
- 默认普通登录用户每日 10 次（`tables.ai.daily-limit`），知识星球正式用户每日 30 次（`tables.ai.star-daily-limit`）；上游调用失败或超时自动退回预扣次数。
